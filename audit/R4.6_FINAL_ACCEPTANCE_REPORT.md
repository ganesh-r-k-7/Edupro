### Deployment Prerequisites (Infrastructure Team)

Before production deployment, the following **must be configured at the infrastructure level**:

1. **TLS Termination** — Configure load balancer with valid certificates
2. **Secret Management** — Store `API_KEYS` in secret manager, inject at runtime
3. **Persistent Storage** — Provision volumes for `/app/models` and `/app/data`
4. **Log Aggregation** — Configure JSON log shipping to central logging
5. **Monitoring & Alerts** — Set up alerts on `/health/ready` failures
6. **Network Policies** — Restrict ingress to API port, egress as needed
7. **Rate Limiting at Scale** — Deploy Redis-backed limiter if clustering

### Post-Deployment

1. Verify `/health/ready` returns 200 with all checks passing
2. Confirm model predictions return expected results
3. Monitor P95 latency < 100ms under load
4. Set up scheduled retraining via GitHub Actions or cron
5. Establish model rollback runbook
