## 5. Known Limitations (Documented)

| Limitation | Impact | Mitigation |
|------------|--------|------------|
| In-memory rate limiting | Single replica only | Redis-backed limiter needed for scaling |
| No API key rotation | Long-lived keys | External key management required |
| No audit logging | Limited forensics | Add middleware for compliance |
| Docker not locally verified | CI validation only | GitHub Actions `docker-build` job |
| Public deployment requires infra security | TLS, DDoS, network policies | Infrastructure team must configure |
